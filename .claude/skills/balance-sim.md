# 밸런스 시뮬레이션

지정된 시스템의 수치 밸런스를 시뮬레이션하고 분석합니다.

## 시뮬레이션 유형

### battle (1v1 배틀)
- 레벨별 데미지 기대값 계산
- ATK/DEF 비율에 따른 데미지 곡선
- 버프/디버프 스택 시 최대/최소 데미지
- 특정 매치업 시뮬레이션 (레벨/스탯 입력)

### capture (포획)
- 레어도×레벨 조합별 포획률 테이블
- 아이템 보너스 적용 시 변화
- 미니게임 성공률 (속도/존크기 기반)

### raid (레이드)
- 보스 HP vs 팀 DPS 계산
- 유나이트 게이지 충전 속도
- 생존 턴 수 추정

### levelup (레벨업)
- 레벨별 필요 캔디/경험치
- 보상 배율 적용 시 레벨업 소요 시간

## 절차
1. 현재 코드에서 관련 공식/상수를 읽습니다
2. Python 스크립트로 시뮬레이션을 실행합니다
3. 결과를 테이블/그래프(텍스트)로 출력합니다
4. 밸런스 이슈가 있으면 조정안을 제시합니다
