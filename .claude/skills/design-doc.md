# 게임 디자인 문서 작성

새 기능에 대한 상세 기획서를 프로젝트 맥락에 맞게 작성합니다.

## 문서 구조

```markdown
# [기능명] 기획서

## 1. 개요
- 기능 설명
- 목적 / 유저 가치

## 2. 상세 설계
- 게임플레이 흐름
- 입력/조작 방식
- 규칙 및 조건

## 3. 수치 설계
- 핵심 파라미터 (기존 GameConstants 기준)
- 밸런스 근거
- 보상 구조 (기존 배율과 정합성)

## 4. 시스템 연결
- 영향받는 기존 모듈 (의존성 그래프 참조)
- Bootstrap 등록 위치
- 새로운 AutoWire 연결
- 세이브 확장 (파일/필드)

## 5. UI/UX
- 화면 흐름 (기존 UI 흐름도 참조)
- 입력 키 배치
- OnGUI 레이아웃 가이드

## 6. 데이터 구조
- 새 ScriptableObject / 클래스 정의
- 기존 SO 확장 사항

## 7. 구현 가이드
- 파일/클래스 목록
- 구현 순서 (의존성 기반)
- 예상 복잡도

## 8. 테스트 항목
- EditMode 테스트 항목
- 수동 테스트 시나리오
```

## 규칙
- 기존 아키텍처 패턴(AutoWire, 이벤트, SO 데이터)에 맞춰 설계
- 밸런스 수치는 기존 기준점과 비교하여 제시
- 세이브 호환성 반드시 고려
