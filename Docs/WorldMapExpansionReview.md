# 전체 맵 연결·이동 검수 — 2026-09-19

## 범위

13개 본 지역과 공통 서브 지역 진입·복귀 경로로 이전 마을 검수를 확장했다. 기존 레벨·수문장 해금과 지역당 단일 외부 입구 조건을 유지한다. 사용자 저장 데이터의 구조와 진행 기록은 바꾸지 않는다.

## 개선

- `WorldRouteLayout`이 실제 필드 길과 전체 지도의 연결선·입구 좌표를 함께 제공한다. 진행 중 아직 잠긴 다른 지역을 관통하던 중심 직선을 외부 우회 경로로 바꾼다. 경로는 유한한 후보점으로 계산하고 캐시한다.
- 지역의 원형 판정과 다른 사각 바닥을 원형 메시로 맞추고, 겹치는 지역 바닥의 높이를 소폭 분리해 겹침 깜빡임을 줄였다. 중복 직선 길과 고도차 없는 경사 길을 제거했다.
- 연못 진입 길과 강을 직각으로 교차시키고, 다리를 길 방향에 맞췄다. 다리 통행 폭에는 강 충돌벽이 들어오지 않는다.
- 주 경로 위에 놓이는 충돌 소품은 생성 위치에서 회피한다. 전체 조합의 실제 충돌 결과는 별도로 기록한다.
- 전체 지도에서 서브 공간의 좌표 `(2000, 0, 2000)`를 그대로 투영하지 않고 해당 입구를 표시한다. 지도 이동은 서브 세계를 복원한 뒤 목적지를 적용하며 이전 클릭·자동 이동을 취소한다.
- 미니맵에 NPC와 입구를 표시하고, 서브 공간에서 메인 세계의 잘못된 목표 방향을 숨긴다.
- 작은 서브 맵의 안전 좌표 탐색이 외벽 바깥을 선택하지 않게 제한했다. 복귀는 원래 접근 위치를 기준으로 하며 환경 이벤트 재구독·태양 조명 선택·안개 모드를 복원한다.

## 실제 지도 UI 검수

저장·계정 시스템을 호출하지 않는 Windows 개발 빌드에서 실제 IMGUI를 촬영했다. 지역 해금·NPC·목표·서브 지역 상태는 메모리에 주입한 검수용 상태이며 실제 진입 조작이나 스토리 진행을 재현한 것은 아니다. 최초 캡처에서 경로선의 패널 밖 그리기와 과밀한 이름 표시를 발견했다. UI 배율을 보존하는 로컬 회전 행렬로 경로선·미니맵 화살표를 수정하고, 지역명은 원 내부에 맞추며 세부 명칭은 선택·가리키기 때 표시하도록 정리했다.

재촬영은 `Artifacts/map-ui-169-corrected` (1280×720)와 `Artifacts/map-ui-43-corrected` (1024×768)에 각각 일반 지도·서브 지역 지도·미니맵 2종으로 보관했다. 경로선이 지도 내부에 연결되고 목표 화살표가 미니맵의 실제 목표 위치에 표시됨을 확인했다. 4:3에서도 패널과 닫기 버튼·범례가 화면 안에 들어온다. 작은 해상도에서 세부 지명 가독성과 모든 입력·노치 조건은 추가 개선·실기기 검수 대상이다.
