# 실제 화면 기반 후속 완성도 개선

## 기준과 범위

기준 이미지는 `Artifacts/model-design-20260918`의 Unity 실제 렌더다. 스타일은 잉크색 UI와 따뜻한 탐험가, 자연색 곤충의 스타일리시 탐험 RPG로 유지한다. 세이브·의상 슬롯·모델 노드 계약과 IMGUI를 보존한다.

1. **형태 정리**: 장수풍뎅이 갑각과 흉부 틈, 사마귀 앞다리 단면을 수정한다. 플레이어와 NPC 모자를 둥근 크라운/챙으로 통일하고 셔츠와 외투 표면 간섭을 제거한다.
2. **실제 전투 검수**: 저장·인증 시스템을 생성하지 않는 독립 QA 씬을 Windows 플레이어로 실행한다. IMGUI가 포함된 대기·명중·복귀·결과 화면과 연속 프레임을 기록한다. 게임의 실제 UI와 전투 코드를 사용한다.
3. **화면 적합성**: 16:9, 4:3, 넓은 모바일 비율에서 아군 왼쪽/적 오른쪽, 상단 HP 카드와 하단 스킬 패널의 가림을 확인한다. 캡처 메타데이터에 실제 해상도를 기록한다.
4. **회귀와 보고**: Unity PlayMode, 저장소 CI, 담당 커버리지 검사 후 같은 각도 모델 전후 이미지와 실제 전투 캡처를 보고한다. Android 기기 성능과 실제 기기 노치 검증은 별도 미완료 항목으로 남긴다.

## 합격 조건

- 주요 연결부에 보이는 틈·튀어나온 단면·표면 깜박임이 없다.
- 캐릭터 생성/필드/미리보기는 공유 빌더를 사용하며 NPC 고정 색과 외형 선택은 유지된다.
- 전투 화면은 모델과 행동을 읽을 수 있고 마지막 공격 후 결과 전환을 확인할 수 있다.
- 테스트 0건이나 카메라 전용 렌더를 실제 UI 검증으로 보고하지 않는다.
- 화면과 실행 결과로 확인한 항목만 완료로 표시한다.

## 이번 실행 결과 — 2026-09-18

다음 후속 구현·실행에서 교체·도주·레이드·배속과 추가 모델 보정을 진행했다. 최신 결과는 `Docs/PolishRegressionRound2.md`를 참조한다. 아래 기록은 1차 검수 시점의 결과다.

### 적용

- 딱정벌레 갑각의 큰 틈과 뿔 접합부, 사마귀 앞다리의 굵은 곡선과 평면 끝을 정리했다. 메시당 172정점을 유지한다.
- 플레이어/NPC의 모자 크라운과 챙을 공유 비례의 둥근 형태로 변경했다. 셔츠를 외투 표면 앞으로 얇게 배치하여 불규칙한 교차면을 제거했다.
- 전투 양측 모델의 실제 경계로 간격을 계산한다. 작은 모델은 가까이 배치하고 큰 날개/뿔은 여유를 확보한다. 곤충 교체 시에도 재계산한다.
- 실제 캡처에서 발견한 도망가기 보조 설명 잘림을 수정했다.

숲 공터의 장수풍뎅이 대 사마귀 Lv15 고정 난수 검수 조합이다. 세이브·인증·보상 저장 서비스를 만들지 않는다. 실제 BattleScreenUI 행동 메서드로 진행하며 화면 HP와 최종 계산 HP를 따로 기록한다. 물리적 버튼 클릭/키 입력 자동화는 포함하지 않는다.

기록 프레임 기준 일반 공격 약 1.78~1.84초, 주요 스킬 약 2.51~2.55초. 마지막 행동은 피격/쓰러짐 대기를 포함하여 약 2.67초 뒤 결과로 전환했다. 약 0.1초 간격의 화면 표본이므로 미세 프레임 단위 보증은 아니다. 영상은 실제 기록 시각에 맞춘 가변 프레임 간격의 무음 MP4이며 속도를 임의로 줄이지 않았다.

### 남은 작업

- 딱정벌레 흉부–머리 경계와 뿔 뿌리, 사마귀의 각진 머리·얇은 날개·낫 끝, 캐릭터 의상 세부 형상은 추가 아트 패스가 필요하다. 현재 결과를 최종 아트 완성으로 판정하지 않는다.
- 모든 종/의상 조합, 실제 버튼 입력, 레이드/교체/도주/상태이상/2배속의 영상 회귀는 아직 미검증이다.
- Android SDK의 `adb devices`에 연결 기기가 없었다. Android 성능 10% 기준, 실제 노치·터치 및 음향 검증은 수행하지 않았다.
- 다음 순서는 위 잔여 형상 보정 → 레이드·교체·도주 UI 회귀 → 실제 Android 기기 비교다.

### 재현

`Tools/Start-UnityValidation.ps1 -Mode BattleBuild`로 독립 Windows 검수 빌드를 만든다. 게임은 `-battleCaptureOut <새 빈 폴더> -screen-fullscreen 0 -screen-width 1280 -screen-height 720`로 실행한다. 배치/그래픽 없는 모드는 거부하며 120초 감시로 멈춘 실행을 종료한다. 이후 `python Tools/Export-BattleCapture.py <캡처 폴더>`로 검은 화면 검사와 MP4 출력을 수행한다. ffmpeg는 PATH 또는 `.claude/cache/ffmpeg-runtime`의 검수용 설치본을 사용한다.
