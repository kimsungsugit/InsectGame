# Hub 실행과 필드 길 안내 — 2026-09-19

## 실행

Unity Hub의 Projects에서 경로가 **`C:\Project\곤충게임`**인 항목을 연다. 설치 버전은 **6000.3.10f1**이다. 같은 이름으로 등록된 `D:\김도현\곤충게임`은 이번 작업본이 아니다.

에디터 컴파일이 끝난 뒤 상단 **Play**를 누르면 정식 `OpeningScene → PlayScene` 경로로 시작한다. 이전 자동 검수 뒤 빈 `Untitled` 씬이 남아 있어도 Play의 시작 씬은 오프닝을 사용한다. 기존 빌드 씬 순서도 오프닝·플레이 순서로 확인했다.

- `Insect Game > Play > Game from Opening`: 정식 시작점을 선택하고 실행한다.
- `Insect Game > Play > Current Scene (development)`: 현재 작업 씬을 바로 실행한다. 이후 일반 Play도 이 선택을 유지하며, 정식 실행 메뉴로 되돌릴 수 있다.

시작점 선택은 프로젝트별 에디터 설정이며 게임 저장 구조나 사용자 진행 데이터의 변환을 추가하지 않는다. 배치 테스트·검수 실행에는 자동 시작점 설정을 적용하지 않는다. 수정 중인 씬은 자동으로 교체하지 않는다.
