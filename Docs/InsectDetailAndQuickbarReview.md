# 탐험 퀵버튼·곤충 정보·모델 검수

## 적용 내용

- 탐험 퀵바를 `도감 / 보유 곤충 / 배틀팀 / 가방 / 퀘스트 / 지도 / 메뉴` 7개로 확장했다. 기존 목적지 ID, 단축키, 알림은 유지한다. 모바일에서는 2열 4행으로 배치하고 마지막 `메뉴` 버튼은 한 줄 전체를 쓴다.
- 도감 상세를 덮던 투명 버튼을 제거해 닫기·이전·다음·회전·색다른 모습 버튼이 입력을 받을 수 있게 했다. 도감 배경 그리드는 상세가 열린 동안 입력을 받지 않는다.
- 도감 `보유 곤충` 카드에 `개체 정보` 연결을 추가했다. 같은 종이 여러 마리여도 `instanceId`로 정확한 개체를 보유 곤충 상세에 연다. 보유 곤충 목록의 카드 본문과 `상세` 버튼도 상세로 이어진다.
- 나비·나방의 떠 있던 더듬이, 누락된 6개 다리와 날개 윤곽, 잠자리의 구형 뒷날개·분리된 날개맥, 개미의 블록형 턱, 사슴벌레 얼굴 아래 떠 있던 블록을 고쳤다. 필드·도감·보유 화면이 공통 모델 생성 경로를 사용한다.
- 도감 상세의 색다른 개체 안내를 모델 프리뷰 아래로 내려 다리와 겹치지 않도록 했다.
- 세로 화면의 도감 상세는 모델과 정보 열을 위아래로 배치한다. 수치에 전체 폭을 주고, 마지막 통계 행까지 상자 안에 들어가도록 높이를 조정했다.

## 검수 범위

위 캡처와 실클릭은 검수용 Windows fixture 결과다. Android 기기 입력·성능과 실제 계정의 저장 데이터는 이 검증에 포함되지 않는다. 모델 갤러리는 정지 이미지이므로 비행·전투 애니메이션의 체감 품질은 별도 플레이 검수가 필요하다. Intel Arc/D3D12의 세로 검수 창은 촬영을 마친 뒤 종료 중 두 번 네이티브 크래시가 났다. 같은 최종 촬영을 D3D11에서 완료하고 정상 종료했으며, 기기 런타임의 안정성을 이 결과로 단정하지 않는다.
