# 모델·전투 후속 검수 — 2026-09-18~19

## 적용한 변경

- 딱정벌레 흉부를 곡면으로 연결하고 뿔을 가로지르던 더듬이를 재배치했다. 사마귀의 삼각형 머리를 둥글게 만들고 날개 두께·안착 위치·낫 끝을 보정했다.
- 실제 교체 화면에서 어두운 글자와 색 네모 아이콘을 확인해 공통 카드, 곤충 썸네일, 교체 가능/쓰러짐 상태 표시로 교체했다.
- 레이드의 큰 반투명 구체가 Windows 실행 파일에서 불투명하게 렌더되어 보스를 가렸다. 몸을 둘러싼 구체를 제거하고 바닥 표식으로 변경했다. 높은 보스 배치를 받치는 지형을 추가했다.
- 레이드 HP·레벨 줄, 다음 행동 안내, 기술·자동 버튼, 합체 게이지를 공통 표면과 읽기 쉬운 배치로 정리했다.
- 도주 성공이 일반 패배와 같은 결과/음악 경로로 처리되던 문제를 `DidEscape` 상태로 구분했다. 성공 화면은 **무사히 이탈**이며 패배 음악 호출을 생략한다. 실제 음향 청취 검증은 포함하지 않는다.
- 전투 판정이 연출의 `UnityEngine.Random` 소비에 영향을 받던 결함을 수정했다. 두 컨트롤러는 독립 `BattleRandomSource`를 사용하고 테스트/검수에는 명시적인 seed를 주입한다. 개체 스탯·세이브 데이터는 변경하지 않았다.

## 실제 촬영

모든 촬영은 저장/인증 시스템 없는 독립 Windows Development 플레이어에서 실제 IMGUI를 포함한다. UI의 행동 메서드를 호출하므로 물리적인 버튼 클릭/터치 검증은 아니다. 프레임 시각을 반영한 무음 MP4를 생성한다.

| 시나리오 | 확인 결과 | 폴더 |
|---|---|---|
| 도주 | 고정 실패 → 적 반격 → 성공 → 무사히 이탈 | `Artifacts/followup-escape` |
| 기절 후 교체 | 교체 선택창 → 사슴벌레 교체 → 전투 결과 | `Artifacts/followup-swap` |
| 공격 중 2배속 | 1배속에서 2배속 전환 후 결과, 동일 행동 HP 흐름 유지 | `Artifacts/followup-speed` |
| 레이드 | 5명 순차 행동 → 보스 예고·반격 → 결과 | `Artifacts/followup-raid-final` |

도주/교체/배속은 각각 100/263/170프레임이며 검은 프레임, 기록된 명중 전 HP 변화, 대기·교체 상태의 좌우 역전이 없었다. 약 0.1초 간격 표본이며 모든 프레임의 수학적 보증은 아니다. 레이드 CSV는 별도 표시 HP를 기록하지만 명중 플래그 기반 자동 동기화 판정은 하지 않는다.

레이드 AOE는 현재 게임 상수 `RaidBossUsesAreaAttack=false`이므로 이번 실제 영상에서 발생하지 않았다. 이 설정을 바꾸거나 AOE 영상 검증을 통과했다고 보고하지 않는다.

최종 레이드는 486프레임으로 결과까지 도달했고 보스 반격을 확인했다. 실제 화면에서 보스 전체가 보이며 팀 HP와 합체 게이지가 겹치지 않는다. 받침 지형은 생성 및 렌더링을 확인했지만 단순한 원통 형태여서 지형과 자연스럽게 연결하는 추가 아트 보정이 필요하다.
